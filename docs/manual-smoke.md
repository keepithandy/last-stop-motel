# Manual Smoke Pass

Use this after a small Last Stop Motel presentation or UI patch.

1. Load the main playable view and confirm the first required interaction is obvious.
2. Move through one normal interaction sequence and verify prompts update correctly.
3. Open and close any changed menu or inspection surface.
4. Reload once and confirm existing state still appears as expected.
5. Check dark-scene readability and control visibility at a narrow mobile width.
6. Confirm visual-only work did not alter progression or persistent identifiers.

Runtime logic changes should also receive a focused automated smoke check where available.
